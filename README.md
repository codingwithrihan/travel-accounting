# Travel Company Accounting Software

A modern, browser-based accounting system designed specifically for travel companies to manage invoices, expenses, clients, and financial reporting.

## Features

### Dashboard
- Real-time financial overview
- Revenue vs Expenses tracking
- Quick statistics cards
- Recent transactions

### Invoice Management
- Create and manage invoices
- Track invoice status (Paid, Pending, Overdue)
- Calculate revenue metrics
- Client-based organization

### Expense Tracking
- Categorized expenses
- Expense approval workflow
- Category-wise expense breakdown
- Amount tracking

### Client Management
- Add and manage clients
- Store contact information
- Track client spending
- Client communication tools

### Financial Reports
- Monthly revenue analysis
- Expense breakdown charts
- Profit margin calculations
- Exportable reports

### Settings
- Company information management
- Financial configuration
- Security settings
- Notification preferences

## Tech Stack

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Charts**: Chart.js
- **Routing**: React Router
- **Icons**: Lucide React
- **Build Tool**: Vite
- **HTTP Client**: Axios
